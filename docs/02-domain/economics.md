## 1. Единицы

- **Рубль вклада** — учетная единица, не деньги на руки.
- **Оплачиваемый час** — час после коэффициентов и капов (`time-accounting.md` §4).
- **Доля** — процент проекта, расчетная величина до юридического закрепления
  (фантомная доля). Не является долей в юрлице и не является ценной бумагой.

| Величина             | Единица в коде                          | Пример                 |
| -------------------- | --------------------------------------- | ---------------------- |
| Деньги               | `Kopecks` = `bigint`                    | `330000n` = 3 300,00 ₽ |
| Проценты (пул, cash) | `BasisPoints` = `bigint`, 1 bp = 0,01 % | `10000n` = 100 %       |
| Доля дня             | `ShareUnits` = `bigint`, 1 = 0,0001 %   | `330n` = 0,0330 %      |
| Время                | `number`, целые секунды                 | `23760` = 6,6 ч        |

> `ShareUnits` и `BasisPoints` — разные шкалы. Формула доли дня
> (`amount × 1e6 / valuation`) дает 1 % = 10 000 единиц доли; формула пула
> (`equity × 10000 / budget`) дает 1 % = 100 bp. Обе формулы нормативны.

## 2. Дневное начисление

```text
paid_seconds   = active + supervised × k_supervised + autonomous × k_autonomous
amount_kopecks = ROUND_HALF_UP(Σ(seconds_seg × rate_seg) × k_quality / 3600)
cash_kopecks   = ROUND_HALF_UP(amount_kopecks × cash_share_bp / 10000)
equity_kopecks = amount_kopecks − cash_kopecks
share_bp       = ROUND_HALF_UP(equity_kopecks × 1_000_000 / valuation_kopecks)
```

- `rate_seg` — версия ставки, действующая на отрезок (R14).
- `k_quality` = 1,0, если модуль качества выключен. Требует обоснования.
- Денежная часть **уменьшает** вклад-рубли, а не добавляется к ним.
- `Σ(seconds_seg × rate_seg)` считается точно, округление одно — на делении на 3600.

Пример: 6,6 оплач. ч × 500 ₽ = 3 300 ₽; `cash_share` 0 → equity 3 300 ₽;
доля дня = 3 300 / 10 000 000 = 0,0330 % (`share_bp = 330`).

> **Решение R-01 (ADR-0003).** Мега-план в §5.2 приводит формулу доли от
> `amount`, а equity-model §3 — от `equity` (`V_person = Σ equity_day`).
> Принята формула от equity: она согласуется с правилом «денежная часть
> уменьшает вклад». На golden-сценариях E-01/E-02 (`cash_share = 0`) обе
> формулы дают одинаковый результат; E-06 фиксирует выбор (`264`, не `330`).

## 3. Накопление и отображение доли

```text
V_person       = Σ equity_kopecks по всем закрытым дням
share_display  = V_person / valuation_current × 100
```

Накопленные рубли **никогда не пересчитываются**. Переоценка меняет
отображаемую долю у всех пропорционально (прозрачное размывание) и
объявляется заранее (`revaluation_notice_days`).

## 4. Пул и режим pending

```text
pool_budget  = valuation_current × pool_pct_bp / 10000
pool_used_bp = ROUND_HALF_UP(Σ equity × 10000 / pool_budget)
```

| Использовано             | Статус  | Поведение                                              |
| ------------------------ | ------- | ------------------------------------------------------ |
| < `pool_info_pct` (80 %) | ok      | обычное начисление                                     |
| 80–90 %                  | info    | предупреждение в дайджесте                             |
| 90–100 %                 | warning | уведомление директору                                  |
| ≥ 100 %                  | closed  | новые дни → **pending**: рубли копятся, доля не растет |

- `pending` определяется по использованию пула **после** добавления вклада дня.
- В pending `share_bp = 0`, а вклад учитывается в `pendingEquityKopecks`.
- Pending снимается решением директора (переоценка или расширение пула).
- Учет времени при closed **не останавливается**.

Дайджест показывает явно: «начислено 3 300 ₽, ожидает переоценки; доля не изменилась».

## 5. Вестинг

Единица — **активный месяц**:

```text
активный месяц = месяц с Σ paid_hours ≥ active_month_min_paid_hours (20)
               (или Σ equity ≥ active_month_min_amount_rub при rule=amount)

AM = число активных месяцев
fraction = 0, если AM < cliff_months
         = min(AM / months, 1) иначе
vested   = ROUND_HALF_UP(share × fraction)
```

- Денежная доля не вестится, если `cash_vesting: false`.
- Ускорение `single_trigger_100`: при смене контроля выше порога fraction = 1.
- Неактивность дольше `inactive_pause_months` приостанавливает вестинг.
- Прогресс месяца показывается как «14,20 из 20,00 ч до активного месяца».

## 6. Статусы участника

| Статус      | Начисления | Вестинг                      |
| ----------- | ---------- | ---------------------------- |
| active      | да         | растет по активным месяцам   |
| paused      | да         | заморожен                    |
| good_leaver | нет        | зафиксирован на дату статуса |
| bad_leaver  | нет        | flagged, решение по договору |

## 7. Начисление и выплата

- `Начислено` — расчетная сумма и доля; всегда с пометкой «не выплата».
- `Выплачено` — запись директора о фактическом перечислении.
- `Остаток к выплате` = начислено − выплачено (по денежной части).
- Доля — расчетный процент вклада, не юридическая доля.
- Дисклеймер виден в дашборде, дайджесте, отчетах и договоре.
