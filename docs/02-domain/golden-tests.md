# Golden-тесты домена

| Поле     | Значение                                         |
| -------- | ------------------------------------------------ |
| Код      | DOMAIN-GOLDEN                                    |
| Версия   | 1.0                                              |
| Фикстуры | `packages/domain/fixtures/golden/scenarios.json` |
| Тест     | `packages/domain/src/golden.test.ts`             |

## 1. Правила

1. Golden-числа — контракт продукта. Расхождение — блокер, а не «допуск».
2. Менять числа можно только через ADR и вместе с нормативной спецификацией.
3. Тесты и документация меняются в одном PR.
4. Каждый сценарий хранит `source` — пункт нормативной спецификации.
5. Деньги в фикстурах — строки (JSON не знает `bigint`), единица — копейки.
6. Время в фикстурах задается **локальными часами** проекта; раннер сам
   переводит их в UTC (это дополнительно проверяет пояс и DST).

## 2. Покрытие

| Группа    | Сценарии  | Что фиксируют                                                         |
| --------- | --------- | --------------------------------------------------------------------- |
| Время     | T-01…T-12 | классы, union, полночь, смена ставки, капы, late, manual, k_quality   |
| Экономика | E-01…E-08 | начисление, месяц, активный месяц, переоценка, pending, cash, вестинг |

## 3. Как читать сценарий

```json
{
  "id": "T-01",
  "kind": "day",
  "source": "time-accounting §13 (T-01)",
  "input": {
    "date": "2026-11-16",
    "sessions": [
      {
        "id": "s-1",
        "membershipId": "dev-1",
        "taskRef": "PC-1",
        "branch": "feat/day",
        "localIntervals": [
          { "class": "active_human", "from": "00:00", "to": "04:00" },
          { "class": "supervised_agent", "from": "04:00", "to": "06:00" },
          { "class": "autonomous_agent", "from": "06:00", "to": "09:00" },
          { "class": "idle", "from": "09:00", "to": "10:00" }
        ]
      }
    ]
  },
  "expect": { "paidSeconds": 23760, "amountKopecks": "330000", "shareBp": "330" }
}
```

Типы сценариев (`kind`):

| kind        | Что проверяет                                                    |
| ----------- | ---------------------------------------------------------------- |
| `day`       | один день; `expect` — поля `DayCalculation`                      |
| `days`      | несколько дат с одной сессией (через полночь); `expect` — массив |
| `month`     | повтор одного дня N раз; `expect` — поля `MonthAggregate`        |
| `valuation` | отображаемая доля при разных оценках                             |
| `pool`      | день с накопленным вкладом; `expect` — пул и pending             |
| `vesting`   | вестинговая доля по активным месяцам                             |

## 4. Запуск

```bash
pnpm test:golden     # только golden
pnpm test            # всё, включая property
pnpm check           # полный quality gate
```

## 5. Добавление сценария

1. Добавить строку в нормативную спецификацию (`time-accounting.md` §9 или
   `economics.md` §8) с точными числами.
2. Добавить сценарий в `scenarios.json` с `source`.
3. Запустить `pnpm test:golden` — новый сценарий должен упасть до реализации
   (TDD), затем пройти.
4. Обновить таблицу покрытия выше.
