# ADR-0004: MCP-поставка и пакет подключения

| Поле   | Значение   |
| ------ | ---------- |
| Статус | принято    |
| Дата   | 2026-11-15 |

## Контекст

Директор и разработчик не должны открывать терминал, редактировать JSON и
устанавливать зависимости. При этом ИИ-клиенты (Claude Code, Cursor, VS Code
Copilot) по-разному обнаруживают MCP-серверы.

## Решение

- Один локальный исполняемый файл `partner-coder.exe` (Bun compile, режимы
  `mcp`, `agent`, `setup`, `doctor`, `version`) без Node/Python на машине клиента.
- Zip-пакет подключения: `START-HERE`, `AGENTS.md`, конфиги `.mcp.json`,
  `.cursor/mcp.json`, `.vscode/mcp.json`, правило `.cursor/rules`, `.vsix`,
  бинарник с `.sha256`, `config/enrollment.key` (одноразовый токен).
- Одноразовый ключ: 256 бит, TTL 7 дней, 1 активация, привязка к устройству;
  в БД хранится только хеш. После обмена ключ удаляется с диска.
- Device token хранится через DPAPI; heartbeat подписывается Ed25519.
- Fallback `partner-coder.exe setup` записывает конфиги и проверяет связь,
  если ИИ-клиент не поддерживает MCP.
- Веб-онбординг повторяет те же шаги, если клиент не справился.

## Последствия

- Плюс: установка = распаковка + двойной клик или диалог с ИИ.
- Минус: нужна подпись Authenticode и борьба с SmartScreen/антивирусами.
- Минус: три матрицы тестирования на чистых Windows VM при каждом релизе.

## Альтернативы

- npm-пакет (`npx`): требует Node и терминала — отвергнуто.
- Только веб-онбординг: не выполняет требование «без терминала» в ИИ-клиенте.
