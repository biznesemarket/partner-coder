# ADR-0005: Публичный репозиторий и source-available

| Поле   | Значение                                        |
| ------ | ----------------------------------------------- |
| Статус | принято (финальный текст лицензии — за юристом) |
| Дата   | 2026-11-15                                      |

## Контекст

Репозиторий публичный: код виден клиентам и партнерам, но коммерческое
использование должно быть ограничено. Публикацию нельзя отменить: история
и форки останутся.

## Решение

- Репозиторий `biznesemarket/partner-coder`, public, ветка `main` защищена.
- Лицензия source-available: код доступен для чтения и аудита, коммерческое
  использование и распространение ограничены (см. `LICENSE`).
- В репозитории нет секретов: только `.env.example`; секреты — в GitHub
  Environments и облачном secret manager.
- Финансовые значения, ключи, персональные данные клиентов, реальные имена и
  данные пилота не публикуются.
- Решение о переходе в private принимается после пилота (M10) с юристом.

## Последствия

- Плюс: прозрачность расчетов повышает доверие; проще нанимать.
- Минус: конкуренты видят архитектуру; нужна дисциплина по секретам.
- Минус: выбранный текст лицензии должен проверить юрист (открытый вопрос).

## Альтернативы

- Proprietary/private: сложнее продавать «прозрачный расчет».
- MIT/Apache: разрешает коммерческое использование конкурентами.
