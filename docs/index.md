# Карта документации

Точка входа в документацию проекта. Здесь только оглавление и назначение
файлов; содержание — в самих документах. Любое добавление, переименование или
смена назначения файла отражается здесь в той же операции.

## С чего начать

1. `AGENTS.md` — правила работы в репозитории (обязательны для людей и агентов).
2. `docs/02-domain/time-accounting.md` — ядро расчета времени.
3. `docs/02-domain/economics.md` — деньги, доля, пул, вестинг.
4. `docs/05-process/development-process.md` — как вести изменения.
5. `docs/adr/` — принятые архитектурные решения.
