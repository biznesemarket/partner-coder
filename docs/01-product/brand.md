# Бренд, домены и почта

Статус: утверждено 2026-11-19.

## 1. Название

| Контекст                                            | Написание       |
| --------------------------------------------------- | --------------- |
| Официальные документы, договоры, счета, интерфейс   | «Партнёр кодер» |
| Письма, неофициальные материалы, английский вариант | Partner Coder   |
| Юридическое лицо правообладателя                    | ООО «ФОНИИ»     |

В официальных документах используется только «Партнёр кодер» (с буквой «ё»).
«Partner Coder» допустим в письмах, англоязычных материалах и там, где нет
официального документа.

Полные реквизиты юрлица хранятся в защищённом реестре и в репозиторий не
попадают.

## 2. Домены

| Домен                   | Назначение                                    |
| ----------------------- | --------------------------------------------- |
| `partnercoder.ru`       | Маркетинг, статьи, привлечение клиентов, help |
| `partnercoder.ru/help`  | База знаний и пользовательские инструкции     |
| `pcoder.ru`             | Рабочий сервис                                |
| `app.pcoder.ru`         | Кабинет клиента                               |
| `admin.pcoder.ru`       | Консоль вендора                               |
| `api.pcoder.ru`         | API                                           |
| `staging.pcoder.ru`     | Тестовый контур: web/консоль                  |
| `staging-api.pcoder.ru` | Тестовый контур: API                          |

Passkeys привязаны к origin и rpID. Смена домена или порта после первого
реального enrollment требует перерегистрации ключей. Поэтому домены считаются
зафиксированными до пилота.

## 3. Почта

| Адрес                  | Назначение                                                     |
| ---------------------- | -------------------------------------------------------------- |
| `info@partnercoder.ru` | Общие вопросы, маркетинг, сайт                                 |
| `support@pcoder.ru`    | Поддержка клиентов                                             |
| `security@pcoder.ru`   | Безопасность, восстановление доступа, чувствительные обращения |
| `billing@pcoder.ru`    | Счета, оплаты, сроки подписки                                  |
| `privacy@pcoder.ru`    | Запросы по персональным данным                                 |
| `info@fonai.ru`        | Юрлицо, бухгалтерия, договоры                                  |

Пароли и резервные коды от почтовых ящиков хранятся только в менеджере
секретов. В репозиторий они не попадают.

## 4. Правила использования

- В интерфейсе, счетах, договорах и официальной документации — «Партнёр кодер».
- В письмах и неофициальных материалах допустим «Partner Coder».
- Не смешивать написания в одном документе.
- Домены и почтовые адреса не менять без отдельного решения: passkeys, ссылки
  восстановления и счета уже будут привязаны к текущим адресам.
