# Глоссарий

| Термин                 | Значение                                                                  |
| ---------------------- | ------------------------------------------------------------------------- |
| Вендор                 | Владелец платформы «Партнёр кодер»                                        |
| Суперадминистратор     | Сотрудник вендора с доступом к консоли клиентов, финансов и лицензий      |
| Финансы вендора        | Роль: счета, платежи, задолженности, продления; без данных разработчиков  |
| Поддержка вендора      | Роль: диагностика онбординга, перевыпуск пакета, отзыв устройства         |
| Клиент / tenant        | Организация-покупатель подписки; изолированное пространство данных        |
| Директор               | Администратор клиента: правила, команда, проекты, выплаты                 |
| Разработчик / участник | Человек, чье время учитывается; входит в tenant                           |
| Пакет подключения      | Zip-архив с одноразовым ключом, MCP-бинарником, конфигами и инструкциями  |
| MCP-сервер             | Локальный процесс, через который ИИ-клиент вызывает инструменты платформы |
| Сессия                 | Период работы разработчика, привязанный к задаче/ветке и устройству       |
| Heartbeat              | Подписанный интервал активности, отправляемый локальным агентом           |
| Политика               | Версионируемый набор правил проекта: ставка, оценка, капы, пул, вестинг   |
| Закрытый день          | Неизменяемая дневная запись после расчета                                 |
| Начисление             | Расчетная сумма и доля за день; **не выплата**                            |
| Выплата                | Фактическое перечисление денег разработчику, отмечаемое директором        |
| Пул                    | Лимит расчетной доли участников в процентах от оценки проекта             |
| Pending                | Режим, когда пул исчерпан: рубли копятся, доля не растет                  |
| Вестинг                | Постепенное «созревание» расчетной доли по активным месяцам               |
| Активный месяц         | Месяц с оплачиваемыми часами не ниже порога (по умолчанию 20 ч)           |
| Онбординг              | Управляемый процесс от пакета до активного tenant                         |
| Фантомная доля         | Расчетный процент вклада; не юридическая доля и не ценная бумага          |
| Класс времени          | `active_human`, `supervised_agent`, `autonomous_agent`, `idle`            |
| Кап                    | Ограничение оплачиваемых часов (дневной или автономного класса)           |
| Компенсация            | Корректировка закрытого дня на дельту; исходная запись не меняется        |
| `input_hash`           | SHA-256 канонического входа расчета; основа идемпотентности               |
| `share_bp`             | Доля дня в единицах 1e-6: 330 = 0,0330 %                                  |
| `pool_used_bp`         | Использование пула в базисных пунктах: 10000 = 100 %                      |
