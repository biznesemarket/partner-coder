# Юридические документы

Здесь размещаются черновики документов для проверки юристом. Тексты не
являются юридической консультацией и не вступают в силу до утверждения.

| Файл                        | Назначение                                                 | Статус      |
| --------------------------- | ---------------------------------------------------------- | ----------- |
| `company.md`                | Реквизиты правообладателя; полные данные — вне репозитория | шаблон      |
| `terms-of-service.md`       | Условия использования сервиса                              | черновик    |
| `privacy-policy.md`         | Политика конфиденциальности                                | черновик    |
| `dpa.md`                    | Обработка персональных данных по поручению                 | черновик    |
| `metadata-consent.md`       | Согласие на обработку метаданных                           | черновик    |
| `equity-disclaimer.md`      | Дисклеймер о расчётной доле                                | черновик    |
| `subscription-agreement.md` | Договор подписки                                           | черновик    |
| `152-fz-checklist.md`       | Вопросы юристу по 152-ФЗ                                   | чек-лист    |
| `license-options.md`        | PolyForm Shield или proprietary EULA                       | предложение |

Ключевые границы:

- «Доля» — расчётный процент вклада, не доля в юрлице и не ценная бумага.
- Платформа не проводит выплаты разработчикам и не оказывает юридические услуги.
- Хостинг в РФ; проверка 152-ФЗ.
- Юридический модуль (реальные доли, опционы, устав) — после пилота.

Порядок проверки: юрист подтверждает каждый документ по пунктам, после чего
статус меняется на «утверждён», а реквизиты подставляются из защищённого
реестра.
