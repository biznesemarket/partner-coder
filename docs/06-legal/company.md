# Реквизиты правообладателя

Статус: шаблон. Полные реквизиты хранятся в защищённом реестре и в
репозиторий не коммитятся.

| Поле                    | Значение                        |

| ИНН                     | `[из защищённого реестра]`      |
| КПП                     | `[из защищённого реестра]`      |
| ОГРН                    | `[из защищённого реестра]`      |
| Юридический адрес       | `[из защищённого реестра]`      |

| Банк, р/с, БИК, корсчёт | `[из защищённого реестра]`      |
| Генеральный директор    | `[ФИО, из защищённого реестра]` |
| Идентификатор ЭДО       | `[из защищённого реестра]`      |
| Телефон                 | `[из защищённого реестра]`      |

Правило: счета, договоры и акты получают реквизиты из бухгалтерской системы
или защищённого реестра, а не из репозитория.
