# Соглашение об обработке персональных данных (DPA) — черновик

Статус: черновик для проверки юристом. Дата: 2026-11-19.

## 1. Стороны

- **Клиент** — юридическое лицо или ИП, использующее Сервис.
- **Исполнитель** — ООО «ФОНИИ», предоставляющий Сервис.

## 2. Роли

Клиент выступает оператором персональных данных своих сотрудников.
Исполнитель обрабатывает данные по поручению Клиента в объёме, необходимом
для Сервиса. Точные термины и статусы проверяет юрист.

## 3. Предмет и данные

Исполнитель обрабатывает:

- учётные данные сотрудников (имя, email, роль);
- метаданные активности (сессии, heartbeat, классы времени, tool calls,
  ветки, задачи);
- технические данные (IP, устройство, журналы).

Исполнитель не получает код, промпты, файлы и скриншоты.

## 4. Цели обработки

- предоставление доступа и расчётов;
- поддержка;
- безопасность;
- биллинг, если это связано с Клиентом.

## 5. Обязанности Исполнителя

- обрабатывать данные только по инструкциям Клиента и для Сервиса;
- обеспечивать конфиденциальность;
- применять меры безопасности;
- привлекать субобработчиков только с уведомлением;
- помогать Клиенту с запросами субъектов данных;
- уведомлять об инцидентах в согласованный срок;
- возвращать или удалять данные после прекращения.

## 6. Субобработчики

Хостинг, SMTP, S3, мониторинг. Перечень ведётся Исполнителем; Клиент
уведомляется об изменениях. Все субобработчики размещают данные в РФ, если
иное не согласовано после проверки 152-ФЗ.

## 7. Безопасность

- шифрование при передаче;
- разграничение ролей и RLS;
- аудит;
- резервное копирование;
- контроль доступа;
- обучение сотрудников.

## 8. Инциденты

Исполнитель уведомляет Клиента без необоснованной задержки, описывает
характер инцидента, затронутые данные и меры. Сроки и формат уточняет юрист.

## 9. Удаление и возврат

После прекращения договора данные удаляются по политике retention, кроме
документов, обязательных к хранению. Клиент может запросить экспорт.

## 10. Аудит

Клиент может запросить подтверждение мер безопасности не чаще согласованной
частоты. Аудит не должен раскрывать данные других клиентов.

## 11. Ответственность

Стороны несут ответственность в пределах договора и закона. Ограничения
ответственности проверяет юрист.

## 12. Приложения

- Приложение 1 — перечень данных.
- Приложение 2 — сроки хранения.
- Приложение 3 — субобработчики.
- Приложение 4 — меры безопасности.
