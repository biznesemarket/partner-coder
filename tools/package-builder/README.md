# tools/package-builder — сборка zip-пакета (M4)

Собирает пакет подключения из `packages/package-template`, подставляет
`config/package.json`, генерирует одноразовый ключ (хеш — в БД), считает
checksum бинарника и .vsix, пишет манифест версии.

Ключ никогда не логируется и не попадает в аудит в открытом виде.
