# tools/seed — демо-данные

Детерминированный seed для local и staging. Создает:

- вендора-суперадминистратора и тариф;
- клиента, договор, подписку, счет и оплату;
- пакет подключения и онбординг-сессию;
- tenant, директора и 3 разработчиков;
- проект, политику и версии ставки/оценки;
- 5 закрытых дней по каждому разработчику (15 `day_records`) с сессиями,
  интервалами, heartbeat и флагами.

Расчет дней выполняется доменным `calculateDay`, поэтому суммы, доли, пул и
флаги совпадают с golden-логикой. Идентификаторы детерминированы: повторный
запуск не дублирует записи.

```bash
docker compose -f deploy/compose/docker-compose.yml up -d postgres
pnpm db:migrate
pnpm seed
```

Выходные данные — JSON со сводкой: tenant, project, число разработчиков,
дней, записей и накопленные суммы.
