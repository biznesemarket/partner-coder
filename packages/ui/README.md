# @partner-coder/ui

Общие React-компоненты кабинетов (M5): таблицы TanStack Table, графики
Recharts, формы, drawer «как посчитано», темы (светлая/тёмная), доступность.

Правила:

- Русский UI; строки — в i18n-каталоге.
- Каждая денежная/долевая цифра форматируется из целых единиц домена
  (`formatRoubles`, `shareUnitsToPercent`, `basisPointsToPercent`).
- Никаких расчетов в компонентах: только отображение готовых значений.
