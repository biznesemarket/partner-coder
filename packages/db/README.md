# @partner-coder/db — схема, миграции, RLS

Реализация запланирована на M2.1 (см. `docs/05-process/development-process.md`).

Планируемое содержимое:

- Drizzle-схема вендорского и тенантского контуров (см. мега-план §6).
- Миграции с ограничениями и индексами.
- RLS-политики и роли БД; `SET LOCAL app.tenant_id`.
- Append-only триггеры для `day_records`, `day_adjustments`, аудита.
- Хеш-цепочка аудита и ежедневный якорь.
- Таблица идемпотентности.

Домен (`@partner-coder/domain`) от БД не зависит: `db` импортирует домен,
не наоборот.
