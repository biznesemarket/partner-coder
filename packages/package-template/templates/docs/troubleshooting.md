# Диагностика

| Симптом                    | Что делать                                                                                                                                                       |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ИИ не видит MCP-сервер     | Проверьте, что папка открыта целиком и в ней есть `.mcp.json` (Claude Code), `.cursor/mcp.json` (Cursor) или `.vscode/mcp.json` (VS Code). Перезапустите клиент. |
| Ключ просрочен             | Запросите новый пакет у поставщика: ключ действует 7 дней.                                                                                                       |
| Ключ уже использован       | Один пакет = одно устройство. Запросите перевыпуск.                                                                                                              |
| Нет сети / прокси          | Проверьте доступ к `api.partnercoder.ru`; при корпоративном прокси обратитесь к администратору.                                                                  |
| Антивирус блокирует `.exe` | Разрешите файл в антивирусе; checksum указан в `bin/partner-coder.exe.sha256`.                                                                                   |
| Ничего не помогает         | Откройте веб-онбординг по ссылке из письма — шаги те же.                                                                                                         |
